# jobcan 自動化プロジェクト

Google Apps Script (GAS) 上で動作する、Jobcan REST API 中継ツールです。

Jobcan から申請データを取得し、スプレッドシートや外部システムから利用できるようにします。スプレッドシートのメニュー操作に加え、Web アプリとして Jobcan REST API へのプロキシ機能も提供しています。

## できること

- スプレッドシートのメニューから Jobcan API トークンを登録する
- Web API（`walk` / `detail` / `requests`）経由で申請一覧・詳細を JSON で取得する
- （デバッグ用）指定条件の申請をアクティブシートへ書き出す

## 利用例：名刺データの取得からサンプル作成

本リポジトリは、名刺データの取得〜サンプルスプレッドシート作成のワークフロー構築のサンプルとしても利用しています。

### フロー（手動〜半自動）

1. jobcan により申請が発生する
2. jobcan から申請通知メールが配信される
3. 通知メールから申請 NO を取得する（スクリプト化可能）
4. jobcan スプレッドシートを開き、メニューからジョブカン接続を押下する（スクリプト化可能）
5. 表示ページの申請 NO 入力欄へ入力する（スクリプト化可能）
6. スプレッドシートへ jobcan 申請データが展開される
7. スプレッドシート上の関数で整形する
8. サンプルスプレッドシートを作成して完了

### スクリプト化可能領域以降の自動化

1. メールではなく、API で進行中の申請 NO を取得する
2. LOG シートに既にある場合は作成済みのためスキップする
3. LOG シートにない場合は名刺作成関数を呼び出す

```bash
npm install
npm run deploy   # typecheck → test → build → clasp push
```

初回のみ `npx clasp login` が必要な場合があります。詳細は [docs/dev.md](docs/dev.md) を参照してください。
