# 利用者向けマニュアル

Jobcan（ジョブカン）の申請データを、スプレッドシートのメニューや Web API 経由で取得するためのツールです。

## できること

- スプレッドシートのメニューから Jobcan API トークンを登録する
- Web API（プロキシ）経由で Jobcan の申請一覧・詳細を JSON で取得する
- （デバッグ用）前日以降の全申請をアクティブシートへ書き出す

## 1. 初回セットアップ：APIトークンの登録

Jobcan API を利用するには、事前に Jobcan 側で発行した API トークンをこのツールに登録する必要があります。

1. 対象のスプレッドシートを開く
2. メニューバーに表示される **「menu」→「認証」** をクリック
3. ダイアログが表示されるので、Jobcan の API トークンを入力して **OK**
4. 「tokenをセットしました」と表示されれば完了

登録したトークンはスプレッドシート単位（スクリプトプロパティ）に保存されます。トークンを再登録したい場合も、同じ手順で上書きできます。

> トークンを入力せず「キャンセル」を押した場合は何も保存されません。

## 2. Web API（プロキシ）の使い方

このツールは Web アプリとしても公開されており、ブラウザや外部システムから URL を叩くことで Jobcan の申請データを JSON で取得できます。

### アクセスURLの確認

1. スプレッドシートのメニュー **「menu」** から表示される画面、または Web アプリの公開URLをブラウザで開く
2. パラメータなしでアクセスすると、利用可能な API 一覧の説明ページ（本マニュアルと同内容の抜粋）が表示されます

URL の形式は以下の通りです。

```
https://script.google.com/macros/s/{デプロイID}/exec?action=...
```

デプロイURLは管理者（開発者）に確認してください。

### 2-1. 申請一覧検索（推奨）：`action=requests`

日付範囲・ステータス・フォームを指定して申請を検索します。条件に一致するデータを全ページ分まとめて返します。

| パラメータ | 必須 | 説明 |
|---|---|---|
| `action` | ○ | `requests` を指定 |
| `start` | - | 申請日の開始日（`YYYY/MM/DD`） |
| `end` | - | 申請日の終了日（`YYYY/MM/DD`） |
| `status` | - | `in_progress` / `completed` / `rejected` / `returned` / `canceled` / `canceled_after_completion` のいずれか。未指定時は全ステータス |
| `form_id` | - | Jobcan 側のフォームID。指定時は `form_name` より優先される |
| `form_name` | - | フォーム名の完全一致。`form_id` 未指定の場合のみ有効 |

例：2026年2月中に完了したフォームID 12345 の申請を検索

```
?action=requests&start=2026/02/01&end=2026/02/28&status=completed&form_id=12345
```

レスポンス例：

```json
{
  "status": "success",
  "count": 2,
  "data": [
    { "id": "108229", "title": "...", "status": "completed", "...": "..." }
  ]
}
```

### 2-2. 進行中申請の一覧取得（旧互換）：`action=walk`

指定日以降に申請された「進行中（in_progress）」の申請を全件取得します。既存連携との互換性のために維持している機能なので、新規に組む場合は `requests` の利用を推奨します。

| パラメータ | 必須 | 説明 |
|---|---|---|
| `action` | ○ | `walk` を指定 |
| `date` | - | `YYYY/MM/DD`。この日以降に申請されたものを対象 |

```
?action=walk&date=2026/02/01
```

### 2-3. 申請詳細の取得（旧互換）：`action=detail`

申請IDを指定し、カスタマイズ項目（詳細入力欄）を含む詳細情報を取得します。

| パラメータ | 必須 | 説明 |
|---|---|---|
| `action` | ○ | `detail` を指定 |
| `id` | ○ | Jobcan の申請ID |

```
?action=detail&id=108229
```

### エラー時のレスポンス

パラメータ不正やAPIエラー時は、以下の形式で返却されます（HTTPステータスではなく、JSON内の `status` で判定してください）。

```json
{ "status": "error", "message": "Parameter 'start' must use YYYY/MM/DD format" }
```

よくあるエラー：

- `start`/`end` の日付形式が `YYYY/MM/DD` になっていない
- `start` が `end` より後になっている
- `status` に許可されていない値を指定している
- `form_id` が正の整数になっていない
- `id`（detail）が未指定
- APIトークンが未登録（「認証」メニューから登録してください）

## 3. デバッグ用：シートへの一括書き出し

開発者向けのメニューまたはスクリプトエディタから `debugFetchAndDump` を実行すると、前日以降に申請された全データ（ID・申請日・フォーム名・タイトル・ステータス・申請URL）が、現在アクティブなシートの末尾に追記されます。通常運用では使用しません。

## 困ったときは

- 「API Token not found」と表示される → 「認証」メニューからトークンを登録してください
- 検索結果が0件になる → `start`/`end`/`status`/`form_id`/`form_name` の条件が絞りすぎていないか確認してください
- それ以外の不明なエラーは、開発者（[docs/dev.md](./dev.md) 参照）に問い合わせてください
