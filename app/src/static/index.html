Jobcan Proxy API 🚀

Jobcan APIへのリクエストを中継するプロキシサービスです。

walk と detail は既存連携との互換性のため維持しています。新規連携では requests を利用してください。
1. 申請一覧検索 (Requests)

日付範囲・フォーム・ステータスで申請を検索します。条件に一致する全ページを返します。

actionrequests
start / end任意。YYYY/MM/DD の申請日範囲
status任意。未指定時は全ステータス
form_id任意。指定時は form_name より優先
form_name任意。完全一致
Example:
Loading...
2. 既存: 進行中一覧取得 (Walk)

指定した日付以降の申請データを全件取得します。

action walk
date YYYY/MM/DD
Example:
Loading...
3. 既存: 詳細取得 (Detail)

申請IDを指定して、カスタマイズ項目を含む詳細を取得します。

action detail
id Jobcanの申請ID
